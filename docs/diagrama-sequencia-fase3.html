Autenticação — Pontos-chave

  • • CPF validado com dígitos verificadores
  • • Consulta parametrizada (SQL injection safe)
  • • Cliente inativo rejeitado genericamente
  • • JWT RS256 com expiração de 900s
  • • X-Correlation-Id propagado em todos os logs

Abertura de OS — Pontos-chave

  • • JWT validado no Django via chave pública
  • • Cliente só vê seus próprios dados (isolamento)
  • • API Gateway → VPC Link → ALB → EKS
  • • NodePort 30080 nos nodes do cluster
  • • Status inicial: ABERTA

Headers Preservados

  • • Authorization (Bearer JWT)
  • • X-Correlation-Id (rastreamento)
  • • X-Request-Id (request-scoped)
  • • traceparent (W3C trace context)
  • • tracestate (vendor tracing)
